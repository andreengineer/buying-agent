# board_reports/

Co-chairman board cycle reports. Sanitized only.

Naming: `BOARD_REPORT_{NN:02d}_{author}.md`
- `NN` = cycle number (01, 02, 03...)
- `author` = `claude` | `gpt` | `hermes` | `andre`

Each report responds to the previous cycle's delta.
Claude writes odd cycles, GPT writes even (default).

First existing report from local: see `BOARD_REPORT_01_claude.md` (to be synced by Claw).
